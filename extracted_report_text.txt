Project Overview 
This project analyses hospital inpatient discharge records to understand and predict Length of Stay (LoS). It uses 
the publicly available New York State SPARCS 2023 dataset, containing over 2.3 million records and 34 
attributes. 
Apache Spark and PySpark are used for data cleaning, processing, aggregation and exploratory machine 
learning. The analysis examines how hospital stay duration varies across age groups, admission types, diagnosis 
categories and illness severity. 
The project aims to demonstrate how Big Data technologies can support historical healthcare analysis and 
resource planning. It does not calculate live bed occupancy or provide clinical recommendations.

1. Real-World Scenario and Problem Statement 
1.1 Scenario and Problem 
Hospitals must manage beds, staff, equipment and medical services while treating patients with different 
conditions and illness severity. 
Length of Stay is an important operational measure because longer stays require hospital resources for more 
days. It varies according to factors such as age, diagnosis, admission type and severity of illness. 
Problem Statement: Analyse a large hospital discharge dataset using Big Data technologies to identify patterns in 
Length of Stay, compare patient and diagnosis groups, and develop a machine learning model to estimate stay 
duration. 
1.2 Stakeholders 
• Hospital Administrators: Understand historical stay patterns for resource planning. 
• Clinical Researchers: Study relationships between illness severity, diagnosis and stay duration. 
• Data Analysts: Develop scalable healthcare data-processing workflows.

• Academic Researchers: Explore Big Data applications in healthcare. 
1.3 Analytical Questions 
The project focuses on the following questions: 
1. What is the average Length of Stay in the dataset? 
2. How does stay duration vary across age groups? 
3. Which admission types and severity levels have longer stays? 
4. Which diagnosis categories have higher discharge counts? 
5. Can machine learning estimate Length of Stay using available patient and admission attributes? 
1.4 Why Big Data; Data Type 
The dataset contains approximately 2.34 million records and 34 attributes. It includes demographic, hospital, 
diagnosis, severity and financial information. 
Its volume and variety make it suitable for distributed processing using Apache Spark. 
The dataset is historical and static, not real-time streaming data

These values must be handled carefully to avoid inaccurate analysis.  
4.5 Preprocessing Plan 
The following preprocessing steps are proposed: 
1. Load the CSV using PySpark. 
2. Standardize column values and identify missing data. 
3. Convert numeric Length of Stay values into a numerical format. 
4. Retain 120 + separately instead of treating it as an exact numeric value. 
5. Remove exact duplicate records. 
6. Handle missing categorical values using an Unknown category where appropriate. 
7. Exclude records with invalid target values from regression training. 
8. Exclude charges, costs and patient disposition from model predictors to prevent data leakage.

5.3 Executable Code 
from pyspark.sql import SparkSession 
from pyspark.sql import functions as F 
from pyspark.ml import Pipeline 
from pyspark.ml.feature import StringIndexer, VectorAssembler 
from pyspark.ml.regression import RandomForestRegressor 
from pyspark.ml.evaluation import RegressionEvaluator 
import time 
 

=== PAGE 8 ===
 
 
start = time.time() 
 
# 1. Initialize Spark 
spark = SparkSession.builder.appName("SPARCS Analysis").getOrCreate() 
 
# 2. Load dataset 
df = spark.read.csv("Hospital_Inpatient_Discharges_2023.csv", 
                    header=True, inferSchema=True) 
 
print("Total Records:", df.count()) 
df.printSchema() 
 
# 3. Data cleaning 
df = df.dropDuplicates() 
 
df = df.withColumn( 
    "LoS", 
    F.when(F.trim(F.col("Length of Stay")).rlike(r"^[0-9]+$"), 
           F.col("Length of Stay").cast("double")) 
) 
 
clean = df.filter(F.col("LoS").isNotNull()) 
 
# 4. Data analysis 
for col in ["Age Group", "Type of Admission", 
            "APR Severity of Illness Description"]: 
    clean.groupBy(col).agg( 
        F.count("*").alias("Count"), 

=== PAGE 9 ===
 
 
        F.round(F.avg("LoS"), 2).alias("Average_LoS") 
    ).show() 
 
# 5. Prepare machine learning data 
features = [ 
    "Age Group", 
    "Type of Admission", 
    "APR Severity of Illness Description", 
    "APR Risk of Mortality" 
] 
 
clean = clean.fillna("Unknown", subset=features) 
 
indexers = [ 
    StringIndexer(inputCol=c, outputCol=c+"_index", 
                  handleInvalid="keep") 
    for c in features 
] 
 
assembler = VectorAssembler( 
    inputCols=[c+"_index" for c in features], 
    outputCol="features" 
) 
 
rf = RandomForestRegressor( 
    featuresCol="features", 
    labelCol="LoS", 
    numTrees=50, 

=== PAGE 10 ===
 
 
    seed=42 
) 
 
pipeline = Pipeline(stages=indexers + [assembler, rf]) 
 
# 6. Training and testing 
train, test = clean.randomSplit([0.8, 0.2], seed=42) 
 
model = pipeline.fit(train) 
predictions = model.transform(test) 
 
# 7. Model evaluation 
for metric in ["mae", "rmse", "r2"]: 
    evaluator = RegressionEvaluator( 
        labelCol="LoS", 
        predictionCol="prediction", 
        metricName=metric 
    ) 
    print(metric.upper(), ":", evaluator.evaluate(predictions)) 
 
# 8. Save results and calculate performance 
clean.write.mode("overwrite").parquet("cleaned_data") 
 
print("Execution Time:", round(time.time()-start, 2), "seconds") 
 
spark.stop()

7.2 Limitations and Improvements 
The project has the following limitations: 
• The dataset represents New York hospitals and may not reflect other healthcare systems. 
• It contains historical discharge records, not live hospital occupancy data. 
• Missing values and top-coded stay durations affect analysis. 
• Length of Stay depends on several factors not available in the dataset. 
• Model predictions may reflect biases present in historical data. 
• The project is educational and should not be used for clinical decisions. 
Future improvements may include testing additional machine learning algorithms, applying model explainability 
techniques and incorporating more recent datasets.

Conclusion 
This project demonstrates the application of Big Data Analytics to hospital Length of Stay analysis using the 
SPARCS 2023 dataset. 
The analysis identifies differences in stay duration across age groups, admission types, diagnosis categories and 
illness severity. PySpark provides a scalable approach to processing the large dataset, while Random Forest 
regression offers a baseline for exploring Length of Stay prediction. 
The findings can support historical healthcare analysis and resource-planning discussions. However, the results 
are limited to the available dataset and should not be treated as real-time hospital measurements or clinical 
recommendations.
